# 🏦 Bank Management System

A simple **console-based Bank Management System** developed using **Java, OOP, JDBC, and MySQL**.

This project demonstrates core Object-Oriented Programming concepts along with database connectivity and CRUD operations. The application runs completely through the console and allows users to create accounts, perform transactions, view transaction history, and manage account information.

---

## 📌 Project Overview

The Bank Management System is a Java-based console application designed to simulate basic banking operations.

The system supports two types of accounts:

- Savings Account
- Current Account

The application uses **MySQL** to permanently store account and transaction data.

Users can perform operations such as:

- Create a Savings Account
- Create a Current Account
- Deposit Money
- Withdraw Money
- Transfer Money
- Check Balance
- Display Account Details
- Calculate Savings Account Interest
- Display All Accounts
- View Transaction History
- Delete an Account
